## 修复

1. 单插槽模型适配器只接受改写后的内容和标签，保留请求的 kind、weight、locked、sort_order。避免模型省略可选属性时，proposal 的默认权重 1 覆盖用户的 50，也避免模型改变插槽顺序或锁定状态。严格 proposal 校验继续保留。
2. 场景编辑器区分可为空的编辑焦点与保存必需的有效层级：物体焦点使用所属层级，收起编辑器时使用有效根层级；保存、导出、本地恢复和场景预览使用同一选择。后端非空及树成员校验未放宽。
3. 修正场景“重写强度”帮助文案：数值越高，改写幅度越大；原说明将方向写反。
4. 人格 kind 允许自定义，但原生 select 没有相应 option 时会误显示第一项“世界观起点”。为当前自定义类型提供显式选项，保留其真实值；最终安装包显示“鼓励策略（自定义）”“叙事风格（自定义）”。

## 仍开放的限制

- 首次关键词候选摘要出现输入未要求的“情人教师”措辞。人工修订后保存；生成质量仍需更大样本评价，不能将 schema passed 当作内容准确。
- 修复后桌面对较长教学方法插槽的两次重写进入 local_fallback，trace 为 repaired；这些没有计作真实 M3 成功。相同原始合成输入的独立 provider 诊断一次成功，简洁输入的桌面 M3 路径也成功，尚不能断言所有长输入的输出可靠性已解决。恢复文本有重复追加倾向，普通编辑区对本地恢复的提示也不充分。
- 本次覆盖构建主流程及上述负例；JSON 配置导入/导出往返、所有删除/撤销组合、最大输入规模、跨平台和全面故障矩阵并未全部实测。不能据此关闭整个 Wave 4/5 或总体模型质量门。
