# 0.3.3

本版本完成 Planning 修订链路及一批已实现功能的独立验收，并清理重复开发记录。仍有16项任务保留在[TODO](../../TODO.md)，其中真实模型质量复核按用户要求暂缓；本版本不宣称所有平台和真实 provider 已验收。

## 产品变更

- Planning：数据库权威的 revision CAS、持久修订预览、显式接受/拒绝、差异展示及查询式恢复。回滚创建新 revision，保留当前进度与 ID；修订保留完整现有 target 集合，不增删 Study Unit、章节或排期。详见[计划修订](../plan-revision.md)。提交：`8d7afbb`、`21323d1`、`1b3be8b`。
- Study：当前单选/填空题契约的键盘、反馈、焦点及44px操作区域。浏览器只渲染持久 Session 读回，不提供服务端评分材料。提交：`ec86e6b`。
- Tavern：统一状态与恢复文案；blocked 表示尚未执行。取消仍不保证停止已经发出的上游计算。提交：`888e91d`。
- 导航：全部10个入口按学习、角色与世界、系统分组；窄屏完整文字菜单、当前组/页语义及断点焦点恢复。提交：`f592c4b`。
- Persona、Scene、Sensory、Tavern：异步状态/错误、错误定位、控件名称及44px触控区域；用户移焦和后台告警不抢焦点。提交：`e13fd02`。
- 后端 SDK 延迟加载及 Tavern 分页性能门完成。提交：`26f59d4`、`547c1dc`；分页工作补齐证据，没有改动分页算法或声称性能提升。
