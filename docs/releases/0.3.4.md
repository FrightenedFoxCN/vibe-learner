# 0.3.4

本版本将 MiniMax-M3 实测发现的运行时问题修复纳入发布，包含 31 个生产代码或共享契约提交。完整行为与提交映射见[模型运行时质量](../model-runtime-quality.md)。

## 已采用改动

- Planning 同轮允许三次详情读取、操作总计四次；修复页码/字符预算、修订单元证据范围、图片消息顺序及严格修复阶段的证据保留。短源不再仅因单元少就判为过粗，估分能力统一表述为学习单元结构元数据评分。
- Study 保留互动题 Markdown 空白，尊重显式取消题目，实际传递 PDF 图片，保留后续场景操作所需的目标身份，移除无匹配材料时编造的兜底引用。
- 记忆检索保留领域、说话者与记录时间，采用有总预算的查询相关原文窗口，稳定多语言词法回退排序。
- Provider 适配完整工具信封的冗余 index，统一 Chat 重试归属，发起尝试前检查期限，保留安全类型化工具修复信息。
- Persona 嵌套结构校验进入现有有界修复；OCR 语言报告只依据实际引擎证据。
- Tavern 降低长历史 preflight 的本地处理成本，保留相同最终上下文与预算。

## 质量和发布边界

第 121 轮后已停止实测。最新生产修复后 850 项后端测试和 116 项定向测试通过；本次本地 `npm run check:release` 已通过，包含共享/Web 检查、850 项后端测试与生产 Web 构建；远端 CI 将独立重跑发布门。缓存提速、模型摘要压缩、macOS Vision OCR 和通用强制成稿策略没有作为生产策略采用。

图像来源理解、人格/指令遵循、引用语义、逐字记忆和时间关系仍有反例。未完成事项及证据见[质量 TODO](../quality/TODO.md)，后续研究从[接手摘要](../quality/research-summary.md)开始；本发布不构成独立模型质量或跨平台安装验收。

`v0.3.4` 标签触发 Desktop Release：版本一致性检查 → `npm run check:release` → macOS DMG、Windows NSIS、Linux AppImage 构建 → 校验和与 GitHub Release。安装包发布是否成功以远端流水线为准。
