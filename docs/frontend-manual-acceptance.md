# 前端人工验收清单

本清单用于前端组件、样式、路由与依赖重构，替代指向不存在测试目录的旧 Playwright 配置。它不替代 `npm run check:release` 或不变量测试。每次执行通用冒烟，并按改动选择涉及的领域；未执行的用例不得记为通过。

## 环境与结果记录

- 使用生产 Web 构建，后端采用独立空 SQLite、临时存储目录及 mock provider；勿连接日常资料库或真实模型。使用浏览器新配置或隐私窗口；准备有可选中文本的小 PDF、测试 Persona、Scene 和两个测试 Tavern Room。
- 检查桌面宽度（如 1280px）与 390px 窄屏。观察 Console 和 Network，确认无异常、资源加载失败、重复写入或页面级横向滚动；长内容只在所属容器内滚动。
- 记录提交、浏览器版本、视口、运行命令与夹具；逐项记录通过、失败或未执行。失败时记录重现步骤与预期和实际结果；截图和网络记录不得包含用户内容或密钥。

## 通用冒烟

- 从首页进入计划、章节对话与 Tavern，再返回；直接打开并刷新本次改动的路由。观察初始、空、加载、错误状态与重试入口。
- 用 Tab / Shift+Tab、Enter / Space 核对操作顺序、可见焦点和可读标签。打开调试浮窗或确认框，检查焦点进入、Tab 不逃逸、Escape/取消关闭、焦点回到触发控件；取消不得发出写请求。
- 在禁用缓存的新页面检查调试浮窗的当前页、全局时间线、统计与导出、存储状态。未触发的视图不得提前下载重依赖；加载期应有可读状态。

## 按域追加

| 域 | 验收项 |
| --- | --- |
| 计划与教材 | 上传并解析测试 PDF，查看检查点和计划生成进度。核对排期纵向顺序及页码锚点；编辑标题、预览修订并接受或取消，刷新确认只读回已提交的变化。 |
| 章节对话 | 切换父章节和子章节，分别检查 Session 切换和预览定位，离开再返回核对草稿。发送带换行和公式的消息，确认懒加载时纯文本可见、加载后公式正确。检查交互题持久化结果与附件；打开 PDF 预览，跳页并选中文本。 |
| Persona / Scene | 新建、编辑、取消删除后继续编辑，再确认删除；刷新核对持久化。含未保存草稿时测试站内跳转取消/确认、浏览器刷新提示，无误提交。 |
| Tavern | 创建或切换两个房间，分页、手动刷新、发送消息；切换房间不串消息、状态或草稿。测试断线恢复及取消，不重复发起同一回合。 |
| 设置、感知工具、用量 | 保存设置后刷新核对持久化；测试禁用态与错误提示。验证文件输入及预览，以及用量的空数据、有数据、日期区间筛选和窄屏局部滚动。 |
