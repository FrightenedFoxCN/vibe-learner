## Planning 内容口径

对作者列出的重点问题复核后，主要结论成立，但不能将所有未在教材逐字出现的练习都称为幻觉。

| 样本 | 独立复核结论 |
| --- | --- |
| equations/evidence-first/0 | 确认内容问题。`a=0` 时任务写“不构成方程”，focus 写“非方程或恒等式”，没有保留来源要求的比较 b 与 c。这里应区分“不是一元一次方程”和“原等式无解/恒成立”；当前写法混淆了它们。六次工具失败属另一条协议证据，不能据此直接断言模型完全没有初始上下文。 |
| probability/baseline/1、evidence-first/0 | 确认未明确保留“首抽为红球”这一条件。反复概括“不放回=1/4、放回=2/5”，容易让读者误学边缘概率。后者写 `1/(1+3)`，可暗示更新后的组成，但没有交代发生何事导致该组成。 |
| probability/baseline/0 | 作者记为局部歧义合理。overview/单条任务省略条件，但后续 today task 和 focus 明确“先抽到 1 个红球后”；不应把整份计划判成完全不懂条件概率。 |
| probability/evidence-first/1 | 作者记为局部歧义合理。focus 有“更新袋内组成（1 红 3 蓝）”，但未显式交代首抽红球，任务仍把 1/4 简写成不放回的一般结论。 |
| python/baseline/0 | 确认无来源的教材结构断言：focus 写“循环留到教材后续章节再学”，与“只有两页、不编造后续章节”的任务边界不符。overview 自称不外推也未消除该矛盾。 |
| python/evidence-first/0 | `names[1]` 是从列表顺序/零基索引可直接推出的合理练习，不是幻觉。“按位置访问会出错”应限定到当前字典实例；字典可以有整数键，整数键也不等于按位置取值。保留局部措辞歧义即可。 |
| python/evidence-first/1 | `names[-1]` 和字典缺键报错是正确 Python 知识，不能称事实错误。负索引不是来源给出的零基正索引规则可直接推出的内容，在“仅根据两页/从零学习”条件下属于未注明的知识扩展；缺键观察是合理拓展练习，但同样未说明拓展范围。应与数学错误、杜撰教材章节分别分类。 |

其余被作者标为未发现实质问题的方程样本保留 a 非零、求解/回代及 a=0 比较 b/c；未发现需要推翻该有限结论的内容。

概率审核数学上合理：不放回且已知首抽红球时，`P(R₂|R₁)=1/4`；未观察首抽颜色时，`P(R₂)=2/5×1/4+3/5×2/4=2/5`。但实验用户目标本身写“不能把第二次概率都写成 2/5”，存在条件省略和引导。下一轮必须在任务及冻结 rubric 中明确条件，避免把受引导的简写全部归因于模型。现有 2/6 与 3/6 “明确问题”计数混合了数学表述、来源归属和扩展范围，不适合称统一事实错误率或比较模型胜负。

## 图像定位复算

独立按公开 fixture 重建 360×200 PNG，得到 4,255 bytes，SHA-256 `d6dbf667030fa5d4282c636c203980637ac2b050240bcbea735303bf77ff48ee`，与六个图像样本证据一致。PyMuPDF 搜索目标 `2x + 3 = 11` 的文字框为像素 `[40, 59.19999695, 160.09600830, 92.17600250]`，归一化后与 audit target_rect 一致。

将模型的 `x,y,width,height` 独立换算成左右上下坐标，逐一计算交集、目标面积和并集；六份证据中的 coverage/IoU 全部一致：

## 多媒体结论边界

填空的公开题干和回复未直接给出答案 4；evidence-first 提供“先消常数项，再消系数”的方法提示，这不等于泄漏最终答案，但若要严格禁止任何解题提示，应另立 rubric。两份提交 999 的实际答案回执均为 false，反馈中答案 4 属提交后内容。单选无题目提交，保留 uncertain，不当作单选功能通过。上述支持作者的有限结果，不证明泛化的答案隔离、全部作答形式、浏览器显示或学习增益。

现有证据支持继续研究工具协议和图像定位；不支持上线 evidence-first/坐标提示优化，也不支持将并行 worker 数、正常 Turn 提交数或同模型 reviewer 包装成已验证多智能体教学收益。
